# Age category checker

Task : classifies a person as child, teenager, or adult.                    
                    
Language: Python

How to run : Open an online python compiler. Copy and paste the code. Click the run button.Enter the numbers when prompted.

Concepts Used
- input()
- int()
- if / elif / else
- comparison operators (<, >, ==)

Code:
```py
age = int(input("Enter your age: "))

if age < 13:
    print("You are a child")
elif age < 20:
    print("You are a teenager")
else:
    print("You are an adult")
```
